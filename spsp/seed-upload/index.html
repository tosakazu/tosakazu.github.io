シードアップロード

CSV を start.gg のシードとして一括反映するツール。 Google Sheets URL またはローカル CSV ファイルから読み込めます。

使い方
  1. start.gg API キーを取得 (初回のみ)
  2. API トークンを入力 → 「💾 保存」でブラウザに記憶 (任意)
  3. 大会 イベント URL または Phase ID を入力 (URL なら自動で Phase 取得)
  4. シードデータを指定 (Google Sheets URL / CSV URL / ローカル CSV ファイル)
  5. 「start.gg にシード適用」を押す
Event URL を入れると自動で Phase ID を取得します。Phase ID 直接指定の場合、 .../seeding/1503940/2132353 の 2 つ目の数字 (phase ID) を入力。
入力ソース
CSV URL の場合、その URL が CORS で外部アクセス許可されている必要があります。
列名 (基本このままで OK)
🔒 入力した API トークンと Phase ID/Event URL はこのブラウザから start.gg にのみ送信されます。 GitHub Pages 側には何も保存・転送されません。「💾 保存」を押した場合のみ localStorage に永続保存します。
