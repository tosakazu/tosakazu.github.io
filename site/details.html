SPSP 詳細解説

SPSP = Saikyo Player SPECIAL。 日本大会対象のスマブラSPプレイヤーランキング。 数式とパラメータの全容。概要 (overview) を先に読むのを推奨。

1. 順位評価 (Banzuke) ポイント計算

各大会の bracket 試合を仮想 DE bracket に再配置 (= seed 順にレートで並べる) し、ラウンドごとに「期待される勝ち」を Elo の logistic 公式で計算してポイント化する。 プレイヤーの実際の placement に応じて「勝ち上がったラウンド数」分のポイント和を貰う。

1.1 gain 関数 (Elo win probability)

gain(r) = 1 − 1 / (1 + 10(r − base) / 400)

r は対戦相手の正規化 Elo レート、base はその層のしきい値。 base < r なら gain > 0.5、base > r なら gain < 0.5。
base は「このランク帯にいる人にとってこのレートの人は脅威か」のしきい値。

1.2 ラウンドポイント (mj)

DE bracket の各ラウンド j で、そのラウンドの「対戦相手集合」 (= シード位置で確率的に当たる相手) の gain を平均し、ε = 0.01 を足す。

mj = ε + mean( max(0, gain(ropp)) for opp in roundj )

roundj はラウンド j で当たる相手のシード集合 (DE losers' bracket 構造から導出)。 レートが floor 以下なら floor にクリップしてから gain 計算。

1.3 大会あたりのポイント

プレイヤーが大会で k ラウンド勝ち上がったら、最初の k 個の mj を合計:

P(大会) = Σj=1..k mj

k は k = max_tier_n(nent) − placement_to_tier(place) で計算 (DE bracket の「敗退ラウンド」由来)。

1.4 集計 (age decay + top-N + position decay)

各プレイヤーの大会別ポイントに次の重みを掛けて合計:

  • age decay: 古い大会ほど重みが小さい。半減期 ~2 年。
    age_decay = 0.97days / 30 (exp_monthly(0.97))
  • position decay: 一人のプレイヤーの大会群を P × age_decay で降順ソートし、最初の topN 個は重み 1、その後は pdi−topN+1。
score = Σi Pi × age_decayi × pos_factor(i)
pos_factor(i) = 1 if i < topN else pdi − topN + 1

1.5 5 層カスケード

5 層を Lv1 → Lv5 と段階的に絞る:

Lv2top 2048 (by Lv1)190070030.3—

各プレイヤーは到達した最高 Lv のスコアでランクづけ (Lv5 まで生き残った人は Lv5 で並ぶ、Lv4 止まりの人は Lv4 で並ぶ、…)。

正規化: 順位評価の gain 関数入力に使う Elo は OpenSkill BT を ×29.48 して max=2500 にシフト。
つまり r は全プレイヤーで一貫したレートになる。
土日祝判定: 大会の開始日〜終了日 (start.gg endAt) のいずれかが土日祝なら weekend 扱い。 金〜土・金〜日のような開催は休日扱い、平日 1 日のみの大会は weekday 扱い。

2. 直対評価のベース: OpenSkill BT (Bradley-Terry)

OpenSkill BradleyTerryFull はベイズ的に (μ, σ) を試合ごとに更新する。 試合確率は P(A wins) = sigmoid((μA − μB) / (β·√2)) (σ → 0 時)。

2.1 デフォルトパラメータ

  • 初期 μ = 25, σ = 25/3 ≈ 8.33
  • β = 25/6 ≈ 4.167
  • ordinal = μ − 3·σ (新人は 0)

2.2 Elo 換算

BT の "log-odds 単位" を Elo の "log-odds 単位" に変換する係数:

ELO_PER_UNIT = 400 / (ln(10) · √2 · β) ≈ 29.48

つまり 1 ordinal 単位 ≈ 29.48 Elo。
elo = ordinal × 29.48
normalized_elo = elo − (max_elo − 2500) で全プレイヤーの最大を 2500 にシフト。

3. 直対評価の gating (M=20)

素の BT は全大会の試合を学習するが、「強い人が練習目的で出てる平日大会」が rating を歪める懸念がある。 そこで per-player gating を導入:

3.1 ロジック

累計大会出場数 tour_count を時系列で running carry
weekend match: 両プレイヤー更新 (通常通り)
weekday match:
  if winner.tour_count <= 20: winner の rating を更新
  else: winner の rating は固定 (相手から学ばない)
  if loser.tour_count <= 20: loser の rating を更新
  else: loser の rating は固定

つまり 新人 (≤20 大会) は平日でも学習対象、ベテラン (>20 大会) は土日祝の試合だけで学習。 新人 vs ベテランの平日試合では、新人だけ rating が動き、ベテランは動かない (歪み防止)。

3.2 なぜ M=20?

4 年スライド評価 (N=196 大会、2023 除外) で M を sweep:

  • M=10: Top 8 τ −0.032 (劣化)
  • M=15: −0.024 (まだ劣化)
  • M=18: +0.002 (相転移点)
  • M=20: +0.013 (最適、Top 8 改善)
  • M=40: −0.001 (大きすぎ、Top 16 +0.023 改善あり)

M=20 が「小さい M で Top 8 を守りながら Top 32 を伸ばす」スイートスポット。

4. 総合評価 (rank avg)

順位評価と直対評価の順位の単純平均:

smash_banzuke_rank(uid) = sort_by_avg( (順位評価_rank(uid) + 直対評価_rank(uid)) / 2 )

スコアそのものではなくランクで平均するので、両方式のスケール差に依存しない。 どちらか片方しか rate されていない人 (片方に登場しない) は default = total_player_count + 1 で穴埋め。

5. 評価指標と検証 (ざっくり)

4 年スライド評価 (N=196 大会、2026年 1月〜4月含む、2023 除外)、6 種類の評価指標で測定:

  • Kendall τ: rank 相関 (scope-restricted)
  • Spearman ρ: rank 相関 (差分ベース)
  • mean |SPR|: log2(seed/place) の絶対値平均 (= シード誤差)
  • RMSE(SPR): SPR の二乗平均
  • Upset rate: 試合のうち下シード勝ち率
  • Mean UF/match: log2(winner_seed/loser_seed) の試合平均

総合評価 (順位評価 + 直対評価 avg) が baseline (順位評価 + BT flat avg) と比べて:

  • Top 8 τ: +0.013 (大改善、Top 8 -0.061 問題解決)
  • Top 32 τ: +0.019 (大改善)
  • Top 16/64/256 τ: ≈ baseline
  • Top 8 |SPR|: 1.2038 (baseline 1.2043 超え)
